## 🚀 COMO RODAR LOCALMENTE PARA TESTES

### PASSO 1
Baixar o **youtube-dlp.exe** e deixar como **yt-dlp.exe** na pasta raiz do projeto

### PASSO 2
Baixar o **ffmpeg**, e criar uma pasta chamada **/ffmpeg/** e dentro dessa pasta deve ser colocado o executável do ffmpeg e as DLLs que estão dentro da pasta **/bin** do ffmpeg instalado

---

## 📦 COMO UTILIZAR A VERSÃO PORTABLE (v.1.0.1)

A **versão Portable** do YoutubeDownloader **não precisa de instalação** e pode ser executada diretamente em qualquer computador com Windows.

### 🔽 Como usar

1. Acesse a aba **Releases** do projeto
2. Baixe o arquivo **.zip** da versão **v.1.0.1 (Portable)**
3. Descompacte o arquivo `.zip` em qualquer pasta do seu computador
4. Clique duas vezes no arquivo **`YoutubeDownloader.exe`**
5. Pronto! 🎉 O aplicativo já estará funcionando

📁 **Observação:**  
Os downloads serão salvos automaticamente na pasta **Downloads** do seu computador.

✅ Não é necessário instalar  
✅ Não precisa configurar dependências  
✅ Basta baixar, extrair e executar

## 📦 COMO APENAS UTILIZAR O EXECUTÁVEL GERADO NA PUBLICAÇÃO (v.1.0.0)

O aplicativo baixa qualquer vídeo de qualquer tamanho no youtube, baixa no formato **mp3 (áudio)** ou no formato **mp4 (vídeo)**!  

A versão disponível hoje é a **v.1.0.0**, o código é otimizado mas pode melhorar muito, e não temos ícones mas iremos providenciar em breve.

Para usar, basta ir em **release**, baixar o executável, instalar, colocar o link do vídeo que você deseja baixar, clicar no formato que deseja, e o download será iniciado para a pasta **Downloads** do seu computador
